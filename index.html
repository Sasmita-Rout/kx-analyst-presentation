What is KX Analyst?

🌐

Web-Browser-Based Tool

Sits on top of kdb+, a powerful database built for handling huge volumes of fast-moving data.

🎨

Visual & Easy-to-Use Interface

Gives people a visual, easy-to-use interface for the same underlying power, instead of requiring specialist code.

👥

Dual-Purpose Environment

Technical developers write and test code directly inside, while business/analyst users import, transform, and explore data without coding.

⚡

Efficient Backend Execution

Everything runs through the browser, but the actual heavy computation still happens on the fast database behind the scenes.

🚀

Wider Technology Adoption

In short, it makes a highly specialized piece of technology usable by a much wider group of people.

Why This Matters

The Data Challenge

Market and time-series data — trades, quotes, ticks — arrives in huge volume and at high speed. kdb+ handles this, but working with it means writing raw q code by hand.

The Skills Bottleneck

Only a small number of specialist q developers can build or modify analytics. Every new report or analysis request goes through them.

The Business Cost

Slowed decision-making, a backlog of requests, and business/quant teams unable to move at their own pace — dependent on engineering availability.

Beyond Our Team — Other Ways This Gets Used

📡

Sensor & Equipment Data

  • Teams working with continuous streams of readings from machines, equipment, or vehicles
  • Load large volumes of readings into tables and save them to disk for later analysis
  • Transform incoming data — clean it up, filter out noise, combine readings into summaries
  • Import raw logs (CSV, JSON) as they come in, and export processed results back out to reports or other systems
🔍

Surveillance & Monitoring

  • Teams watching large volumes of transaction or event data for unusual patterns
  • Build alert rules directly in q — flag abnormal volume, repeated suspicious patterns, spikes against a historical baseline
  • Visual Inspector helps spot the pattern visually, not just in raw numbers
  • Example: exchanges and broker-dealers use kdb+-based systems like this for market abuse and fraud detection
💻

q Developers

  • Analyst Orbit works as a genuine all-in-one IDE — development and testing live in the same environment
  • Write code, execute it, debug it, then run QCumber tests immediately after — no context-switching
  • Git is integrated too, so review and version control happen in the same place
  • Useful especially where q developers are spread across different offices/locations
🔁

Analyst Orbit Building Analyst Orbit

  • The Analyst Orbit team itself uses Analyst Orbit to build and test Analyst Orbit's own components — dogfooding its own product
  • Since Analyst Orbit is largely written in q, developers iterate on Analyst Orbit's own modules from inside Analyst Orbit
  • QCumber tests Analyst Orbit's own code changes before release — the same tool every other team uses
  • Makes Analyst Orbit a self-iterative tool — improvements get validated using the product itself before reaching users

Inside the IDE — What Each Menu Does

EDIT = change code · Q = run/understand code · TOOLS = use Analyst's toolkit · HELP = learn how it works

Q Menu — Work with Code

  • Execute — run selected q code
  • Inspect — explore a result visually
  • Profile — find slow code
  • Go to Definition — jump to where something is defined
  • Uses (Selection) — find everywhere something is used
  • Bench — measure how fast code runs

Tools Menu — Analyst's Toolkit

  • Scratchpad — temporary q/Python playground
  • Remote Scratchpad — run code against a remote kdb+ process
  • Visual Inspector — view tables/results as readable visuals
  • Visual Profiler — visual performance breakdown
  • Table Importer / Exporter — bring data in/out (CSV, JSON, ODBC)
  • Table Transformer — point-and-click ETL

Help Menu — Learn As You Go

  • Feature Overview — product tour
  • Keyboard Reference — shortcut cheat sheet
  • Q Reference — full q language docs
  • Analyst Orbit Function Reference — Analyst's own library docs
  • Analyst Orbit User Guide — full how-to guide
  • Notes & Troubleshooting — known issues, fixes
